## Agent 插件

- [DeepSeek Harness 插件](https://github.com/busabase/busabase-dsh-plugin) - 通过 MCP 工具、实体卡片和实时检查器将 DeepSeek Harness 接入 Busabase，并采用审批优先的写入机制。[npm](https://www.npmjs.com/package/@busabase/dsh-plugin)

## ORM 适配器

- [Drizzle ORM 驱动](https://github.com/busabase/drizzle-busabase) - 将类型安全的 Drizzle 查询转换为 Busabase SDK 调用，无需生成或解析 SQL。[npm](https://www.npmjs.com/package/drizzle-busabase)
- [Kysely 方言](https://github.com/busabase/kysely-busabase) - 通过非 SQL 方言，在 Busabase Base 上执行类型安全的 Kysely 查询。[npm](https://www.npmjs.com/package/kysely-busabase)

## 工作流自动化

- [n8n 社区节点](https://github.com/busabase/n8n-nodes-busabase) - 提供记录增删改查操作，以及经过签名验证的新建或更新记录 Webhook 触发器。[npm](https://www.npmjs.com/package/n8n-nodes-busabase)

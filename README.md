## Agent Plugins

- [DeepSeek Harness Plugin](https://github.com/busabase/busabase-dsh-plugin) - Connects DeepSeek Harness to Busabase with MCP tools, rich entity cards, a live inspector, and approval-first writes. [npm](https://www.npmjs.com/package/@busabase/dsh-plugin)

## ORM Adapters

- [Drizzle ORM Driver](https://github.com/busabase/drizzle-busabase) - Translates typed Drizzle queries into Busabase SDK calls without generating or parsing SQL. [npm](https://www.npmjs.com/package/drizzle-busabase)
- [Kysely Dialect](https://github.com/busabase/kysely-busabase) - Executes typed Kysely queries against a Busabase Base through a non-SQL dialect. [npm](https://www.npmjs.com/package/kysely-busabase)

## Workflow Automation

- [n8n Community Node](https://github.com/busabase/n8n-nodes-busabase) - Provides record CRUD actions and verified webhook triggers for new or updated Busabase records. [npm](https://www.npmjs.com/package/n8n-nodes-busabase)

## Official Resources

- [Busabase](https://github.com/busabase/busabase) - Open-source, local-first database and workspace for AI agents, with human-reviewed changes.
- [Busabase Documentation](https://busabase.com/docs) - Product concepts, setup guides, API references, and integration documentation.
- [Busabase Skills](https://github.com/busabase/skills) - Reusable agent skills and MCP integration resources for working with Busabase.
